Setup and Publishing Procedures

A practical guide: run the FFJ Consulting website locally, preview documentation, and publish Enhanced KIRO content from the private FFJ-DocsPublic repo to the live site.

2. Prerequisites

  • Node.js v18+ and npm — required for the React frontend
  • .NET 8 SDK — optional; only needed if you run the C# backend
  • Python 3 — optional; for start.py and serving static docs locally
  • Git — version control and GitHub sync
node --version
npm --version
dotnet --version   # optional

3. Run the FFJ website locally

The website is a React + Vite app in frontend/. Choose one method:

Option A — Frontend only (most common)

Use this when editing content, docs, resume, or UI. Backend is not required for most pages.

cd /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC/frontend
npm install          # first time only
npm run dev

Open http://localhost:3000

Option B — Python start script (frontend + backend)

cd /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC
python3 start.py

Starts the C# API on port 5000 and the React app on port 3000.

Option C — Shell script

cd /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC
./run-local.sh

What you can browse locally

  • http://localhost:3000 — home page, landing animation, all React routes
  • http://localhost:3000/resume — resume page
  • http://localhost:3000/docs — deployed docs portal (frontend/public/docs/)
  • http://localhost:3000/docs/index.html — same docs portal directly

5. Add Enhanced KIRO docs to the FFJ website

When you are ready to publish Enhanced KIRO on ffjconsultingllc.com, follow these steps:

Step 1 — Copy from private repo to the website

cp -r /Users/fjabbari/REPO_CURSOR/FFJ-DocsPublic/ \
  /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC/frontend/public/docs/enhanced-kiro/

Step 2 — Remove the draft banner

Edit frontend/public/docs/enhanced-kiro/index.html and remove the yellow "Draft for review" banner before going live.

Step 3 — Add a card to the docs portal

Add to both Docs/index.html and frontend/public/docs/index.html:

<div class="card enhanced-kiro-card">
    <div class="card-icon">⚡</div>
    <h2 class="card-title">Enhanced KIRO</h2>
    <p class="card-description">Enterprise AI development framework — governed, connected, measurable</p>
    <a href="enhanced-kiro/index.html" class="card-link">View Documentation →</a>
</div>

Add to Docs/styles.css and frontend/public/docs/styles.css:

.enhanced-kiro-card { border-top: 4px solid #667eea; }

Step 4 — Add navigation link (optional)

In frontend/src/components/Navigation.jsx, add a link to the docs:

<li><a href="/docs/enhanced-kiro/" target="_blank" rel="noopener noreferrer">Enhanced KIRO</a></li>

Optionally add Kiro to frontend/src/data/tools.json on the home page Tools section.

Step 5 — Preview on local website before deploy

cd /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC/frontend
npm run dev

Verify at http://localhost:3000/docs/enhanced-kiro/

Step 6 — Commit and deploy to AWS

cd /Users/fjabbari/REPO_CURSOR/FFJ-CONSULTING-LLC
git add frontend/public/docs/ frontend/src/
git commit -m "Publish Enhanced KIRO documentation to website"
./deploy-with-new-domain.sh

Deploy targets: S3 bucket ffj-consulting-website, CloudFront E3545N3N8YO2FZ.

Step 7 — Verify production

  • https://ffjconsultingllc.com/docs/enhanced-kiro/
  • Hard refresh (Cmd+Shift+R) or incognito if CloudFront cache shows old content

See also: Unpublished Work for provenance, sanitization, and review checklist.

6. Sync this Docs/ portal to the live website

Cards like Setup and Publishing live in Docs/ first. To show them on the public site at /docs:

  1. Copy changed files from Docs/ to frontend/public/docs/
  2. Or copy the whole folder when many cards changed: cp -r Docs/* frontend/public/docs/
  3. Preview at http://localhost:3000/docs
  4. Commit and run ./deploy-with-new-domain.sh

Rule of thumb

Edit in Docs/ for documentation work.
Copy to frontend/public/docs/ before previewing on the website or deploying.
Edit in FFJ-DocsPublic/ for Enhanced KIRO content — copy to frontend/public/docs/enhanced-kiro/ only when publishing.

7. Typical workflows

Workflow A — Edit website content only

  1. Edit files in frontend/src or frontend/public
  2. npm run dev → preview at localhost:3000
  3. Commit, push, ./deploy-with-new-domain.sh

Workflow B — Edit Enhanced KIRO docs (stay private)

  1. Edit HTML in ~/REPO_CURSOR/FFJ-DocsPublic
  2. Preview: python3 -m http.server 8081
  3. Commit and push to private FFJ-DocsPublic repo on GitHub
  4. Do not copy to FFJ website until ready

Workflow C — Publish Enhanced KIRO to website

  1. Complete review checklist (see Unpublished Work)
  2. Follow Section 5 above
  3. Deploy
